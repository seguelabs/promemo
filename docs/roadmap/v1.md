# v1: Git-Native Workflows

Goal: Promem can summarize repository state so memory evolves with code.

## Deliverables

- `promem snapshot <feature> --dry-run`.
- `--json` output for snapshot data.
- Current branch collection.
- `git status --short` collection.
- `git diff --stat` collection.
- `git diff --name-only` collection.
- Recent commit collection.
- TODO/FIXME scanner.
- Secret redaction warnings before snapshot content is saved.

## Success Criteria

- A developer can inspect feature progress from current repo changes without
  copy-paste.
- Snapshot output is structured enough for future AI extraction and MCP tools.
- Snapshot behavior is covered by integration tests using temporary Git repos.

## Out Of Scope

- Automatically saving snapshot output into `.promem/`.
- AI-generated memory.
- Automatic commits.
