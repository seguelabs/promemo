# v7: Team Workflows And External Importers

Goal: Promem can support team-scale memory workflows and import useful context
from adjacent development systems when the product needs it.

## Deliverables

- GitHub PR comment importer.
- Issue tracker importer.
- Optional hosted team mode investigation.
- Web dashboard investigation.
- Team-oriented review workflow for generated memory.
- Policies for sensitive files, redaction, and cloud provider use.
- Documentation for merge-friendly memory maintenance.

## Success Criteria

- Teams can bring important PR or issue context into `.promem/` without storing
  noisy raw transcripts.
- Hosted or dashboard work remains optional and does not compromise local-first
  usage.
- Sensitive data handling is explicit before any team or cloud workflow ships.

## Out Of Scope

- Making hosted mode mandatory.
- Storing raw chat transcripts.
- Replacing Git as the durable collaboration layer.
