# a0: Smart Search Foundation

Goal: Promemo can search memory by meaning, not only by exact words.

## Deliverables

- Chunk `.promemo/**/*.md` into searchable units.
- Keep the existing keyword search path.
- Add semantic search behind `--semantic`.
- Add a local generated search cache under `.promemo/cache/`.
- Add basic filters for feature, document type, status, and tags.
- Add `promemo sync` to build or refresh derived search indexes.

## Commands

```bash
promemo sync
promemo sync --rebuild-index
promemo search "auth tokens" --semantic
promemo search "webhook retry" --json
```

## Success Criteria

- Search can find relevant decisions even when the query wording does not
  exactly match the Markdown text.
- Generated search artifacts are reproducible and uncommitted.
- Keyword search remains available without semantic dependencies.

## Out Of Scope

- Query rewriting.
- Reranking.
- Graph expansion.
- Hosted search service.
