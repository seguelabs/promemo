# a0: Smart Search Foundation

Goal: Promem can search memory by meaning, not only by exact words.

## Deliverables

- Chunk `.promem/**/*.md` into searchable units.
- Keep the existing keyword search path.
- Add semantic search behind `--semantic`.
- Add a local generated search cache under `.promem/cache/`.
- Add basic filters for feature, document type, status, and tags.
- Add `promem sync` to build or refresh derived search indexes.

## Commands

```bash
promem sync
promem sync --rebuild-index
promem search "auth tokens" --semantic
promem search "webhook retry" --json
```

## Success Criteria

- Search can find relevant decisions even when the query wording does not
  exactly match the Markdown text.
- Generated search artifacts are reproducible and uncommitted.
- Keyword search remains available without semantic dependencies.

## Out Of Scope

- Query rewriting.
- Reranking.
- Graph expansion.
- Hosted search service.
