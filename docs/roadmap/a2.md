# a2: Memory Graph

Goal: Promem understands relationships between features, files, decisions, APIs,
and notes.

## Deliverables

- Frontmatter support for type, status, related features, references, and tags.
- Relationship extraction from frontmatter and Markdown references.
- Generated graph cache.
- `promem graph <feature>`.
- `promem related <feature>`.
- `promem load <feature> --include-related`.
- Depth-limited related context expansion.

## Commands

```bash
promem graph auth
promem related payments
promem related checkout --depth 2
promem load checkout --include-related
```

## Success Criteria

- Promem can identify related project areas without manually loading everything.
- Graph output is inspectable and deterministic.
- Graph data is derived from Markdown/frontmatter and remains out of Git.

## Out Of Scope

- Visual dashboard.
- Hosted graph API.
- Automatic code dependency analysis beyond references captured in memory.
