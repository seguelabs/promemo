# a3: Memory Quality

Goal: Promem helps keep memory current, trustworthy, and conflict-free.

## Deliverables

- Status values for accepted, proposed, experimental, deprecated, superseded,
  stale, conflicting, and unknown memory.
- Review dates and staleness signals.
- `promem status`.
- `promem stale`.
- `promem review`.
- `promem conflicts`.
- `promem resolve`.
- Warnings during `load` when stale or conflicting memory affects context.

## Commands

```bash
promem status
promem stale
promem review
promem mark auth --status accepted
promem conflicts
promem conflicts authentication
promem resolve
```

## Success Criteria

- Users can see which memory needs review.
- Promem can flag contradictory decisions before they silently enter context.
- Deprecated and superseded memory is excluded by default where appropriate.

## Out Of Scope

- Fully automatic conflict resolution.
- Raw transcript auditing.
- Team approval workflows.
