# a3: Memory Quality

Goal: Promemo helps keep memory current, trustworthy, and conflict-free.

## Deliverables

- Status values for accepted, proposed, experimental, deprecated, superseded,
  stale, conflicting, and unknown memory.
- Review dates and staleness signals.
- `promemo status`.
- `promemo stale`.
- `promemo review`.
- `promemo conflicts`.
- `promemo resolve`.
- Warnings during `load` when stale or conflicting memory affects context.

## Commands

```bash
promemo status
promemo stale
promemo review
promemo mark auth --status accepted
promemo conflicts
promemo conflicts authentication
promemo resolve
```

## Success Criteria

- Users can see which memory needs review.
- Promemo can flag contradictory decisions before they silently enter context.
- Deprecated and superseded memory is excluded by default where appropriate.

## Out Of Scope

- Fully automatic conflict resolution.
- Raw transcript auditing.
- Team approval workflows.
