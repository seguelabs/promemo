# v6: Editor And Assistant Integrations

Goal: Promem fits into the tools developers already use without weakening the
local-first core.

## Deliverables

- VS Code extension prototype.
- Cursor-compatible workflow notes.
- JetBrains plugin investigation or prototype.
- Terminal UI investigation.
- Assistant-specific prompts and setup docs.
- Integration contract that requires every external surface to call the core
  engine.

## Success Criteria

- Developers can load and save memory from at least one editor surface.
- Editor integrations do not duplicate `.promem/` file-writing behavior.
- The CLI remains the source of truth.

## Out Of Scope

- Hosted dashboard.
- Team permissions.
- Replacing MCP as the assistant automation path.
