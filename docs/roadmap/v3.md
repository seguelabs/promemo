# v3: MCP Integration

Goal: MCP-capable assistants can read and write Promemo memory through the same
core engine as the CLI.

## Status

Complete.

## Deliverables

- [x] `promemo mcp` stdio server.
- [x] `promemo_load_context` tool.
- [x] `promemo_search` tool.
- [x] `promemo_save_memory` tool.
- [x] `promemo_preview_memory` tool.
- [x] `promemo_extract_memory` tool.
- [x] `promemo_memory_schema` tool.
- [x] `promemo_list_features` tool.
- [x] `promemo_tree` tool.
- [x] `promemo_doctor` tool.
- [x] `promemo_read_feature_file` tool.
- [x] `promemo_snapshot` tool.
- [x] MCP resources and prompts for common memory workflows.
- [x] Stable CLI-wide machine-readable error envelopes for failed `--json`
  commands, so MCP and automation clients can handle failures consistently.
- [x] Provider extraction returns the exact generated `MemoryInput` alongside
  its preview/save report, so approval flows can save reviewed memory without
  re-running extraction.

## Success Criteria

- [x] An MCP-capable assistant can load context, search memory, and save distilled
  memory into `.promemo/`.
- [x] MCP code does not duplicate Markdown writing logic.
- [x] Tool contracts are covered by tests.
- [x] Failed `--json` CLI commands return a stable error shape with a code, message,
  and optional details instead of plain text only.

## Out Of Scope

- Editor extensions.
- Web dashboard.
- Hosted synchronization.
