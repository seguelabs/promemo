# v3: MCP Integration

Goal: MCP-capable assistants can read and write Promemo memory through the same
core engine as the CLI.

## Deliverables

- `promemo mcp` stdio server.
- `promemo_load_context` tool.
- `promemo_search` tool.
- `promemo_save_memory` tool.
- `promemo_list_features` tool.
- `promemo_snapshot` tool.
- MCP resources and prompts for common memory workflows.
- Stable CLI-wide machine-readable error envelopes for failed `--json`
  commands, so MCP and automation clients can handle failures consistently.

## Success Criteria

- An MCP-capable assistant can load context, search memory, and save distilled
  memory into `.promemo/`.
- MCP code does not duplicate Markdown writing logic.
- Tool contracts are covered by tests.
- Failed `--json` CLI commands return a stable error shape with a code, message,
  and optional details instead of plain text only.

## Out Of Scope

- Editor extensions.
- Web dashboard.
- Hosted synchronization.
