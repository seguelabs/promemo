# v3: MCP Integration

Goal: MCP-capable assistants can read and write Promem memory through the same
core engine as the CLI.

## Deliverables

- `promem mcp` stdio server.
- `promem_load_context` tool.
- `promem_search` tool.
- `promem_save_memory` tool.
- `promem_list_features` tool.
- `promem_snapshot` tool.
- MCP resources and prompts for common memory workflows.

## Success Criteria

- An MCP-capable assistant can load context, search memory, and save distilled
  memory into `.promem/`.
- MCP code does not duplicate Markdown writing logic.
- Tool contracts are covered by tests.

## Out Of Scope

- Editor extensions.
- Web dashboard.
- Hosted synchronization.
