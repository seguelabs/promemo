# v5: Search Intelligence And Graph Features

Goal: Promemo can retrieve compact, relevant project context from larger
repositories.

## Deliverables

- Chunking.
- Local search cache.
- Embeddings cache.
- Semantic search.
- Hybrid keyword and semantic search.
- Related feature expansion.
- Token-budgeted context loading.
- Feature, decision, and file relationship graph.
- Graph export for inspection and debugging.

## Success Criteria

- `promemo load` can produce compact context for large projects.
- Search can answer why-oriented project questions better than keyword matching
  alone.
- Promemo can identify related features, decisions, and files.
- Generated indexes remain reproducible and uncommitted.

## Out Of Scope

- Hosted search service.
- Mandatory cloud embeddings.
- Replacing Markdown as the source of truth.
