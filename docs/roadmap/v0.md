# v0: Local Markdown Memory MVP

Goal: Promemo works as a local CLI for saving, loading, listing, and searching
project memory.

## Deliverables

- Single-crate Rust CLI.
- `promemo init` creates `.promemo/` structure.
- `promemo save-json <feature>` reads structured JSON from stdin.
- `promemo load <feature>` produces prompt-ready context.
- `promemo list`, `promemo tree`, `promemo search`, and `promemo doctor`.
- JSON output for automation-friendly commands where useful.
- `.promemo/index.json` tracks saved features.
- `.gitignore` excludes generated caches and indexes.
- README quick-start examples.
- Sample `examples/memory.json`.
- Clear errors for malformed JSON and missing features.

## Success Criteria

- A developer can save structured feature memory, commit it, and load it later.
- The CLI can be used without any network service or AI provider.
- Tests cover init, save-json rendering, load output, list/index behavior,
  keyword search, and doctor checks.
- Binary-level integration tests exercise the compiled CLI.

## Out Of Scope

- AI extraction.
- MCP server.
- Semantic search.
- Multi-crate workspace.
- Hosted service or web UI.
