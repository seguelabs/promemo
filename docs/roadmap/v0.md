# v0: Local Markdown Memory MVP

Goal: Promem works as a local CLI for saving, loading, listing, and searching
project memory.

## Deliverables

- Single-crate Rust CLI.
- `promem init` creates `.promem/` structure.
- `promem save-json <feature>` reads structured JSON from stdin.
- `promem load <feature>` produces prompt-ready context.
- `promem list`, `promem tree`, `promem search`, and `promem doctor`.
- `.promem/index.json` tracks saved features.
- `.gitignore` excludes generated caches and indexes.

## Success Criteria

- A developer can save structured feature memory, commit it, and load it later.
- The CLI can be used without any network service or AI provider.
- Tests cover init, save-json rendering, load output, list/index behavior,
  keyword search, and doctor checks.

## Out Of Scope

- AI extraction.
- MCP server.
- Semantic search.
- Multi-crate workspace.
- Hosted service or web UI.
