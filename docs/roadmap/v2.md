# v2: Extraction And Provider Automation

Goal: Promem can extract structured memory from notes, handoffs, and snapshots
using a configured provider.

## Deliverables

- Provider trait.
- OpenAI-compatible provider.
- Config loading from `.promem/config.toml`.
- Command that turns handoff text into `MemoryInput` JSON.
- Optional local provider path after the OpenAI-compatible path is stable.
- Review-before-save flow for generated memory.

## Success Criteria

- Promem can produce useful structured memory from unstructured notes.
- Raw handoff text and transcripts are not stored.
- Provider output maps into the same JSON contract used by `save-json`.

## Out Of Scope

- MCP server.
- Hosted team mode.
- Provider-specific UI.
