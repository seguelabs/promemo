# a4: Repo Importers

Goal: Promemo can import useful repo-adjacent knowledge without becoming a raw
archive.

## Deliverables

- `promemo import handoff`.
- `promemo import github-pr`.
- `promemo import adr`.
- GitHub issue importer.
- Linear/Jira importer investigation.
- Slack thread importer investigation.
- Import pipeline that extracts summary, decisions, files, TODOs, and open
  questions.
- `store_raw_sources = false` by default.

## Commands

```bash
promemo import handoff handoff.md --feature authentication
promemo import github-pr 123 --feature payments
promemo import adr docs/adr/001-auth.md
```

## Success Criteria

- Imported memory is distilled into `.promemo/` Markdown instead of storing raw
  source material by default.
- GitHub PR and ADR imports preserve decisions and file references.
- Importers call the core memory engine instead of writing `.promemo/` directly.

## Out Of Scope

- Browser-wide capture.
- General personal memory.
- Hosted importer service.
- Storing raw transcripts by default.
