# a1: Smart Context Loading

Goal: `promem load` can produce compact, ranked context for an assistant or LLM.

## Deliverables

- Query rewriting for search/load goals.
- Reranking of candidate chunks.
- `--smart` loading mode.
- `--max-tokens` output budgeting.
- `--current-only` filtering to avoid stale or superseded memory.
- JSON output that exposes selected chunks, scores, and warnings.

## Commands

```bash
promem load auth --smart
promem load auth --max-tokens 8000
promem load auth --current-only
promem search "admin theme" --smart
```

## Success Criteria

- Smart load returns smaller and more relevant context than loading every file.
- Stale or superseded memory is excluded when requested.
- Output remains explainable enough for users to inspect why context was chosen.

## Out Of Scope

- Memory graph traversal.
- Contradiction resolution.
- Editor integrations.
