# v4: Packaging And Distribution

Goal: Promem is easy to install, upgrade, and run on developer machines.

## Deliverables

- Release builds for macOS, Linux, and Windows.
- Shell completions.
- Homebrew formula or tap.
- Install script for direct binary installation.
- GitHub release workflow.
- Version command and release metadata.
- Basic generated usage docs from the CLI.

## Success Criteria

- A developer can install Promem without cloning the repository.
- Releases are reproducible from tagged commits.
- The CLI reports its version and supported commands clearly.

## Out Of Scope

- Hosted service.
- Editor extensions.
- Team synchronization.


Goal: Promem can retrieve compact, relevant project context from larger
repositories.

## Deliverables

- Chunking.
- Local search cache.
- Embeddings cache.
- Semantic search.
- Hybrid keyword and semantic search.
- Related feature expansion.
- Token-budgeted context loading.
- Feature, decision, and file relationship graph.

## Success Criteria

- `promem load` can produce compact context for large projects.
- Search can answer why-oriented project questions better than keyword matching
  alone.
- Generated indexes remain reproducible and uncommitted.

## Out Of Scope

- Hosted search service.
- Mandatory cloud embeddings.
- Replacing Markdown as the source of truth.
